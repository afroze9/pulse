Method and Limits

Thresholds: 4.5:1 for ordinary text; 3:1 for large text and essential control boundaries/focus indicators. Ratios use sRGB relative luminance and computed foreground/background colors with opacity compositing. Gradients are flagged separately; the note-panel gradient was reviewed at both endpoints (worst light stop 5.45:1; dark 6.25:1). Disabled controls, logos, and decorative separators are excluded where WCAG permits.

This is a scoped contrast audit, not a full accessibility certification. The browser run uses isolated fixture responses and never loads or modifies the user's Jira data. Native title-bar colors are checked mathematically from source; native platform popup/focus rendering and every possible imported item state are not exhaustively measured. Gradient/image backgrounds, overlap, backdrop filters, forced-colors mode, and all accessibility semantics require separate review.

Reproduce

Run npm run dev -- --port 5190 --strictPort, then npm run test:contrast -- final with Playwright and Edge available. If Playwright is installed outside the repository, set PULSE_PLAYWRIGHT_MODULE to its package directory. Optional: PULSE_PREVIEW_URL and PULSE_CONTRAST_OUTPUT. The script stubs all API requests with the fixture and aborts mutation requests. Reports and screenshots are written under artifacts/contrast. Run npm test for the palette regression checks.
